# Cockpit Tools 登录自动填（油猴脚本 v2.3.1）

在 Cockpit Tools 里点「登录」后，Safari 会打开 `auth.openai.com` 登录页。

**面板默认不出现**：点 Safari 工具栏上的 Tampermonkey 图标 → 菜单里选「Cockpit 自动填：打开/关闭面板」，
右下角才会弹出面板。

**账号靠粘贴识别**：面板里有一个输入框，把含账号密码的一段文字粘进去，脚本自动抠出邮箱和密码
（不用去页面上读，也不要求这个账号在账号库里）。一次登录只在第一次填入前弹一次确认框，确认后才把
**邮箱 / 密码 / 动态验证码** 填进输入框。

**它只填不提交**：Continue、授权、验证等按钮全部由你自己点。

> 项目交接文档：<a href="HANDOFF.html">HANDOFF.html</a>（当前状态、下一步、红线）

## 一条命令更新账号

账号从 Cockpit Tools 的加密账号库（`~/.cockpit_tools`，AES-256-GCM）**只读**解析，不修改它的任何配置或数据：

```bash
cd openai-auto-log-in
node scripts/gen-userscript.mjs
```

产物：`userscript/cockpit-codex-fill.user.js`（含明文密码，权限 600，已在 `.gitignore` 里，别外传）。
增删账号后重跑一次，然后按下面第 2 步覆盖安装。

## 安装（一次性）

> ⚠️ **不要把这个 .user.js 拖进 Safari 窗口**：Safari 27.2（macOS 27.2）的拖放处理有 WebKit 崩溃 bug
> （crash log 栈在 `WebPageProxy::performDragOperation`，SIGSEGV 空指针），拖任何脚本文件都可能让 Safari 崩。
> 用下面的方式安装。

1. 本机已装 `Tampermonkey.app`（5.6.6243）。
2. Safari → 设置 → 扩展 → 勾选 Tampermonkey。
3. 跑安装助手（会自动起一个本地地址、把脚本复制到剪贴板、并在 Safari 打开安装页）：

   ```bash
   cd openai-auto-log-in
   node scripts/install.mjs            # 20 分钟后自动退出
   ```

   - 页面里点「点这里安装脚本」→ Tampermonkey 弹安装页 → 安装；
   - 如果 Tampermonkey 没拦截、页面只显示源码：打开 Tampermonkey 面板 →「添加新脚本 / +」→ 清空 → ⌘V 粘贴 → ⌘S 保存
     （脚本内容已经由安装助手放进剪贴板了）。
4. 第一次在登录页生效时，Safari 可能询问是否允许 Tampermonkey 访问 `auth.openai.com`、`chatgpt.com`、
   `platform.openai.com`、`wzyp.cn`、`2fa.nloop.cc` 等域名 → 按提示允许。

## 用法

1. Cockpit Tools 点某账号的「登录」→ Safari 打开登录页。
2. 点 Tampermonkey 图标 → 「Cockpit 自动填：打开/关闭面板」→ 右下角出现面板（再点一次收起）。
3. 把含账号密码的文字**粘进面板里的输入框**，脚本自动识别邮箱和密码，面板显示
   「识别到：xxx · 密码 Pa*****!（点此显示/隐藏）」或「识别到：xxx（无密码，需手动填）」。
   支持的粘贴格式：

   | 粘贴内容 | 识别结果 |
   |---|---|
   | `user01@example.com----PASSWORD123` | 邮箱 + 密码 |
   | `user01@example.com\|PASSWORD123`、`user01@example.com:PASSWORD123`、`user01@example.com PASSWORD123` | 同上 |
   | `PASSWORD123----user01@example.com`（密码在前） | 同上（邮箱正则不允许连续连字符，不会把 `PASSWORD123----user01` 当邮箱） |
   | `账号：user01@example.com 密码：PASSWORD123`（也认 `password: …`、`pass: …`、`pwd: …`，全角 `：` 同样有效） | 同上 |
   | 只有 `user01@example.com` | 只识别邮箱；若这个邮箱在已保存列表里会回退用其密码，否则密码步骤需要你手填 |
   | `user01@example.com----PASSWORD123 2FA: JBSWY3DPEHPK3PXP` | 邮箱 + 密码 + 2FA 密钥（也认 `密钥：`、`totp:`、`otpauth://…?secret=…` 链接） |

   - 密码候选会做校验（ASCII 可见字符、4–64 位、含字母或数字、不是「另一个邮箱地址」或「密码/账号」这类标签词；
     密码本身以 `Pass:`/`password:` 开头时会回退为整段当密码），
     尾部多余分隔符（如 `user01@example.com----PASSWORD123----`）会被剥掉；
     所以 `user01@example.com 请勿修改密码`、`user01@example.com----`（空密码）都不会把干扰文本当密码。
   - 面板和确认框里密码默认**掩码显示**（如 `RV**76`），点面板那行字可切换显示/隐藏，方便你填入前核对。
   - 识别不到邮箱时面板提示「没识别到邮箱，检查粘贴内容」，不会乱填。
   - 如果 ⌘V 粘不进去（少数站点会拦截粘贴），点面板上的 **「读剪贴板」** 按钮，脚本会自己读剪贴板；
     仍然不行就直接在框里手打。
   - **同邮箱会自动合并**：粘贴的邮箱如果账号库里已经存在，不会多出一个重复条目 —— 直接选中库内那条，
     并**用粘贴的密码覆盖库内密码**（取码地址仍用库内配置），面板提示「已合并到库内账号：… （覆盖库内密码）」。
   - 也可以不用粘贴，直接从下拉框选**账号库里已有的账号**（粘贴后再选库内账号会以库内账号为准）。
4. 点「填入」→ **先弹确认框显示本次账号和掩码密码** → 确定后才填。
   - 邮箱页填邮箱 / 密码页填密码 / 验证码页自动查 6 位动态码并填入，然后你自己点 Continue。
   - 验证码默认走 `https://2fa.nloop.cc`；粘贴的邮箱如果正好在账号库里，会用该账号配置的取码地址。
5. 勾「换步后自动填」后，换到密码页、验证码页时会自动填 —— **一次登录只确认一次**：第一次填入前弹确认框，确认后同一账号的后续步骤直接填，不再打扰；你在确认框点「取消」时本次不再自动重试，但仍可手动点「填入」重试。
   注意：**自动填只在面板打开时生效**；面板收起时勾着也不会填（避免它在你没打开面板时突然动页面）。
6. 面板右上角只在**识别到步骤时**才显示「邮箱 / 密码 / 验证码」标签；页面上没有登录输入框时不显示任何标签。
7. **保存与管理**：粘贴识别到的账号可以点「保存账号」存进插件（Tampermonkey 本地存储），
   下次打开面板直接在下拉框里选；点「管理」列出所有账号，每行有 `✎`（修改）和 `✕`（删除）。

   - 保存的是**插件自己的列表**，不会写回 Cockpit Tools 账号库；
   - 保存的邮箱如果和库内账号相同，会用保存的密码 / 2FA 覆盖库内（下拉里标注「已保存·覆盖」），删掉这条就回退；
   - 删除即时生效，刷新页面也不会回来；删掉的库内账号会进「已删除（可恢复）」，随时能点「恢复」找回；
   - `✎` 可以**手动修改 账号 / 密码 / 2FA 密钥**；改库内账号会生成一条「已保存·覆盖」，改邮箱时旧邮箱自动隐藏。
8. **每个账号三个框都要填满**（`管理 → ✎`）：

   | 框 | 内容 |
   |---|---|
   | 账号 | 登录邮箱 |
   | 密码 | 该账号密码 |
   | 第三个框 | **取码方式**：2FA 密钥（base32）或取码邮箱，二选一 |

   - 验证码统一从第三个框取：是 base32 → 本地算 TOTP；是邮箱 → 用这个邮箱去取码服务查码；
   - **没有 2FA 的账号**，第三个框留空保存时会**自动填成登录邮箱**（等价于"用登录邮箱取码"，和原来一样）；
   - 登录邮箱改过、但 MFA 仍由原邮箱收码的账号：第三个框填**辅助（原）邮箱**，取码就走原邮箱；
   - 密码为空不允许保存；第三个框内容既不是邮箱也不是 base32 时会被拒绝并提示。

9. **导出**：点「导出」把全部账号逐行导出，同时复制到剪贴板并下载 `cockpit-accounts-日期.txt`。格式就是粘贴能直接读回的写法：

   ```
   user01@example.com----PASSWORD123
   user02@example.com----PASSWORD456 2FA: JBSWY3DPEHPK3PXP
   user03@example.com----PASSWORD789 AUX: old.mail@example.com
   ```

   （有 2FA 密钥的账号带 ` 2FA: 密钥`；取码邮箱和登录邮箱不同的带 ` AUX: 取码邮箱`；
   两者都没有的只有邮箱和密码。把导出的文本再粘回面板可以原样识别。）

## 确认策略：一次登录只确认一次

- 第一次填入（自动或手动）前弹一次确认框：显示本次账号 + 掩码密码，你点确定后才填；
- 同一账号在这次登录里的后续步骤（密码页、验证码页）**不再弹确认**，直接填；
- 换账号（下拉改选、重新粘贴）会重置，下次填入重新确认；
- 点「取消」则本次不再自动重试，可手动点「填入」重来。

风险提示：免掉重复确认后，页面一旦被劫持/仿冒、或你粘错账号文本，就没有每步的「本次填入使用账号 xxx」可核对了。
第一次的确认框是唯一一道人工刹车，建议看清楚再点确定。

## 2FA（独立验证器密钥）

账号有独立 2FA 密钥时，脚本**在本地用标准 TOTP（RFC 6238，SHA-1 / 30 秒 / 6 位）算码**，
不需要打开 `2fa.fun`、`browserscan` 这类第三方网站 —— 不联网、不限流、站点挂了也不影响。
反过来，把密钥交给第三方网站只是为了看一眼码，不划算；它们最多用来人工核对。

- 密钥来源：粘贴时带 `2FA: XXXX` / `密钥：XXXX` / `otpauth://totp/...?secret=XXXX`，或在「管理 → ✎」里手填；
- 没填 2FA 密钥的账号保持原来的方式：按邮箱去 `2fa.nloop.cc` 查码；
- 验证码页点「填入」→ 有密钥就地算，没有就查接口。

## 安全与限制

- **明文密码 / 2FA 密钥**：面板里「保存账号」写入的密码和 2FA 密钥都存在 Tampermonkey 的 GM 存储里（明文）。若给 Tampermonkey 开了云同步，密码会随之上云 —— 请不要开同步，或只用邮箱/验证码代填。
- 生效域名（`@match`）：
  `auth.openai.com`、`auth0.openai.com`、`chatgpt.com`、`chat.openai.com`、`platform.openai.com`、`wzyp.cn`。
  其他站点要加 `@match` 后重新生成。
- 填充规则按通用登录页写的（`input[type=email]` / `input[type=password]` / 一次性验证码输入框）；
  `wzyp.cn` 上如果是自助发号/登录页，能识别就用，识别不了面板会显示「未识别」，不会乱动页面。
- 若某平台登录页是客户端内嵌窗口，或 Cockpit 用无痕/私密窗口打开（需额外允许扩展运行），脚本注入不到。
- 有些验证码页填满 6 位会自动提交，这种情况下「不提交」由页面决定，脚本无法阻止。
- passkey、Google 登录等没有密码步的流程，脚本会停在「未识别」，需要你手动操作。
- 邮箱正则不允许「连续连字符」，所以 `a--b@c.com` 这类邮箱会被截断、punycode（`a@xn--fiqs8s.cn`）完全不识别；
  粘贴后请先核对面板里的识别结果（面板和确认框都会显示邮箱，填之前能看出来）。
- 粘贴的密码以掩码显示，文本格式不规范时仍可能误判（面板会显示识别结果，确认框里也有掩码密码，建议核对后再点确定）。
- 动态码来自账号里配置的 `mail_url`（当前是 `https://2fa.nloop.cc`），换成别的取码服务需要改 `userscript/template.user.js` 的 `fetchCode`。
- 不代填手机号/短信码，也不处理 Cloudflare 人工验证。

覆盖：
- 入口：面板默认隐藏、收起时即使开了自动填也不动页面、菜单命令注册、点菜单出现 / 再点收起；
- 同邮箱合并：粘贴库内已存在邮箱 → 不产生重复条目、选中库内账号、用粘贴密码覆盖并填对；
- 2FA：本地 TOTP 与独立实现一致、粘贴识别密钥、保存带密钥、验证码页用本地码填且不请求取码接口；
- 辅助邮箱：粘贴识别取码邮箱、保存后按辅助邮箱取码、没填时仍按登录邮箱取码、导出带 AUX 且能粘回；
- 三个框：无 2FA 时第三框自动存登录邮箱、留空保存回落登录邮箱、密码为空拒绝保存；
- 确认策略：自动填只在第一步确认一次，换到密码步不再确认且能自动填上；
- 导出：带 2FA 的账号输出密钥、无 2FA 的不带该字段；
- 空账号库：管理区不出现「库内账号」分组和「没有可用的库内账号」占位；
- 手动编辑：改账号/密码/2FA 生效、旧记录被替换、改库内账号改名后旧邮箱隐藏；
- 保存/管理：保存后进列表并出现在下拉、刷新后仍在、管理区列出、删除后刷新不回、覆盖库内密码在删除后回退；
- 右上角标签：无输入框页不显示「未识别」、识别到邮箱时显示「邮箱」；
- 粘贴识别：`email----password`、密码在前、`password:`/`pwd:` 标签（含冒号后空格、换行）、中文标签、多邮箱取有合法密码的那个、
  双密码文本不出脏值、`P@ss` 这类含 `@` 的密码、尾部分隔符剥离、中文干扰文本/空密码不误判、只有邮箱、无邮箱不误填、
  确认框带掩码密码、粘贴后改选库内账号；
- 填充：邮箱 / 密码 / 验证码（单框、分段），每种都断言表单未被提交；
- 确认：取消后不填值、不反复弹窗；冷却期内手动点击可重试且有反馈；
- 自动填：localStorage 预置后开面板即填、只确认一次、不重复触发；
- `@match` 覆盖 6 个域名（OpenAI 登录域 + ChatGPT + 取号站）；
- SPA 换步（URL+DOM 同时变）：email→密码、email→验证码都不再重复确认，验证码只取码 1 次；
- release 产物：无调试后门、无通配 `@connect`、同时匹配 `auth.openai.com` 与 `wzyp.cn`。

测试会把 debug 构建写到 `.cache/test/debug.user.js`（含明文密码、权限 600、已被 `.gitignore` 忽略），用完可删。
